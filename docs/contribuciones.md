##  Metodología de Trabajo Colaborativo
1. **Ramas por Funcionalidad:** Cada integrante desarrolla su módulo en una rama independiente (`feature/nombre-modulo`) desprendida de la rama principal `main`.
2. **Revisiones y Merge:** Una vez finalizada la tarea, se abre un *Pull Request* en GitHub para que el equipo revise el código antes de integrarlo a la rama `main`.
3. **Control de Cambios:** Todos los commits siguen convenciones claras de nomenclatura (`feat:`, `fix:`, `docs:`) para facilitar la lectura del historial del repositorio.
