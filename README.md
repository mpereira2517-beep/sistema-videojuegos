# Sistema de Colección de Videojuegos 

Sistema web desarrollado para la gestión de una colección personal de videojuegos, aplicando buenas prácticas de desarrollo front-end, persistencia local y flujo de trabajo colaborativo con Git y GitHub.

* **Benjamín Alejandro** (Validaciones de datos y formulario de registro)
* **Gerónimo Nahuel** (Catálogo, buscador y filtros por género/plataforma)
* **Gerónimo Pereira** (Módulo de edición y eliminación de videojuegos)
* **Ciro Atuel** (Colección de carátulas predeterminadas y gestión de imágenes)

## Tecnologías Utilizadas
* **HTML5** para la estructura semántica de las vistas.
* **CSS3** para el diseño y estética visual con temática gamer.
* **JavaScript (ES6+)** para la lógica del sistema, manipulación del DOM y gestión de eventos.
* **JSON y LocalStorage** para la persistencia y carga inicial de datos.
* **Git y GitHub** para el control de versiones colaborativo mediante ramas (*feature branches*) y Pull Requests.
